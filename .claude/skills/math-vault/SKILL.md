# math-vault:数学知识库笔记生成

把一本数学/理论性教材,逐节转成"深度理解型"的 Obsidian 笔记——不是搬运定义,而是讲清每个概念**为什么这样定义、几何上是什么、和别的概念怎么连**。目标是建成一个能长期复习、彼此双链的知识网络。

## 这个 skill 的灵魂:理解先于形式

普通笔记是"定义→定理→例子"的搬运。这个 skill 要做的恰恰相反:**先给具体直觉(几何画面、动机问题、最朴素的例子),让形式定义像是被直觉逼出来的结果。** 读者合上书应该能自己重建定义,而不是背下来。

关键拿捏(这是用户反复强调的):**手法要用,痕迹要藏。**
- 不要在正文写"我们先来看见…""现在给出定义"这类点破手法的元话语,也不要写小标题叫"先看见再定义"。
- 不要提及任何教学法来源或风格名号(如某视频作者),笔记里只有数学本身。
- 直接把几何画面、动机问题自然地写在定义前面,让行文顺下来。读者感到流畅,而非被告知"我在用某种方法"。

> 为什么这么要求:用户喜欢"具体直觉→抽象定义"的教学顺序,但觉得反复点破手法、点名来源很啰嗦、出戏。把方法内化成行文本身,才显得自然、像一个好老师在讲,而不是在演示一套模板。

## 工作流程

### 第 0 步:确认输入与节奏

接到任务先弄清三件事:
1. **材料在哪**:PDF 路径 / 用户粘贴的文字 / 截图。
2. **学科与书名**:用于 frontmatter 和目录命名。
3. **目录结构**:读教材目录,确认按"小节"(如 1A/1B/2.1/2.2)切分。每个小节一篇笔记是默认粒度——足够聚焦,导航清爽。

**节奏默认:先做一节给用户看效果,确认风格火候后再批量推进。** 不要闷头一次做完整章,风格跑偏时代价大。第一节确认后,后续可连续做。

### 第 1 步:提取原文(内容必须 100% 来自材料)

铁律:**笔记内容必须完全来自用户提供的材料,绝不凭记忆补充或"发挥"数学内容。** 提取不到就停下来报错说明,不要编。详见 [[feedback_math-solver-no-fabrication]] 的同源原则。

提取方式:
- **默认用 Read 工具直读 PDF 页**(指定 pages 参数分段读),或直接读用户粘贴的文字/截图。模型自行识别公式转成 LaTeX。
- **公式密集、符号复杂、或发现读偏**时,提示用户可切换 pix2text OCR(把公式精确转 LaTeX)。参考 math-solver 的 `scripts/pdf_ocr.py`。详见 [[feedback_ocr-pix2text-workflow]]。
- 读原文时要读全一节的完整知识链(定义、性质、例子、关键习题),再动笔。宁可多读几页,不可漏掉推导环节。

> [!important] 预算管理:读和写分两步走,别挤在一轮里
> 读一整节 PDF(往往七八页图像)很吃上下文预算。实测发现:若在同一轮里既读完大量 PDF 页、又紧接着写 7KB+ 的长笔记,容易在落盘前预算耗尽——图(短文件)能写出来,长 markdown 却反复卡住写不完。
> 应对:**先把这一节的原文要点提取/摘录成精炼文字(定义、定理、例子的核心),再开新一轮专心写笔记。** 摘录这一步把厚重的 PDF 图像压成轻量文本,后续写作轮次就不必再背着整本书的图像预算。尤其用子代理跑、或一次处理多节时,务必这样拆,否则长笔记落不了盘。

### 第 2 步:按模板写笔记

每篇笔记的骨架见 `references/note-template.md`。核心板块:本节地图 → 动机/直觉切入 → 定义 → 性质(配证明思路)→ 例子 → 易错点 → 知识点联系(双链)→ 自测题。

写作要点见 `references/writing-guide.md`——这是 skill 的精华,务必读。

### 第 3 步:配 SVG 矢量图(默认高密度 + 关键处动画)

几何直觉用 SVG 矢量图承载(Obsidian 原生渲染 `![[xx.svg]]`)。图存到 vault 的 `assets/` 目录,笔记里用 `![[文件名.svg]]` 嵌入。

- **【最高优先级】只画"能跟着演算一遍"的过程型图**:画每张图前先自查"读者能不能跟着它把这一步计算几何地走一遍?"——能才画;只是讲意义/关系/决策(并排对照、概念关联、选择树)的一律不画。详见 `svg-guide.md` 末节「演算型判据 + 标注规范」。
- **【最高优先级】每张图必须自带标注,消除分散注意**:① 每条线就地标注它代表的量/方程/是哪个面的影子,禁用远处图例;② 顶部放浅色"本图演算"框,点名这张图在演算笔记里的哪行公式;③ 正文里的关键量与图同色(如 `dz` 蓝/`dx` 红);④ 节制只标这步要用的量;⑤ 一图一步。图要紧贴它解释的那段文字+公式。
- **配图密度按高标准:一个概念配一张图(约为早期笔记的 3 倍)**,把几何直觉拆细,别一节只配一两张。但每张都须是演算型。
- **关键处加 SMIL 动画**:在"过程比结果重要"的概念(逼近、运动、变换、累加、生长)上做声明式动画,**过程型动画必须循环播放**(`repeatCount="indefinite"` + `values` 往返),否则几秒播完跟静图没区别;同时画终态虚线参照保证静止态可读。详情见 `references/svg-guide.md` 动画规范一节。

画图规范、配色、坐标系约定、配图密度、动画规范、**演算型判据 + 标注规范(末节,最高优先级)**与可复用片段见 `references/svg-guide.md`。

### 第 4 步:写入 Obsidian 并打开确认

- 笔记路径:`<学科库根>/第N章 章名/小节号 小节名.md`(如 `advanced-math/LADR线性代数/第1章 向量空间/1A R^n和C^n.md`)。
- 图路径:`<学科库根>/assets/小节号-图名.svg`。
- 用 MCP 的 `vault_write` 写入,写完用 `open_file` 在 Obsidian 打开给用户看。
- 经 Obsidian Local REST API + MCP 操作 vault,详见 [[project_obsidian-mcp]]。

## 公式格式

- 行内公式用 `$...$`,独立公式用 `$$...$$`(Obsidian MathJax 原生支持)。
- 向量、集合等用规范 LaTeX:$\mathbf{R}^n$、$\mathbf{F}$、$\in$、$\subset$ 等。
- 性质/公理用表格罗列时,保留教材原有的中英文术语对照(若原书有)。

## 双链命名约定

- 笔记互链用 `[[小节号 小节名]]`,如 `[[1B 向量空间的定义]]`。
- 命名风格全库统一,前向引用(链到还没做的节)是允许的——它标记"待写",不是错误。

## 扩展性说明

本 skill 当前以数学/理论教材为主。模板和写作手法(直觉先行、深度理解、双链)对其他理论学科(物理、理论计算机等)同样适用,换学科主要改 frontmatter 标签和示例领域即可。语言类(英语等)笔记结构差异较大,应另建独立 skill。
